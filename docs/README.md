# Documentation Index

This directory contains long-lived design documents. Per `AGENTS.md` rules:

- `docs/` root holds only finalized, authoritative design documents (product, architecture, protocol, security, deployment, data model, test strategy, etc.).
- `docs/plans/` holds draft proposals and in-progress implementation plans — not authoritative.
- `docs/reviews/` holds review records, issue lists, and retrospective summaries — not authoritative.

When a plan or review produces a durable rule, it must be written back to the relevant root-level design document and referenced from this index.

Cross-document references must point to root-level design documents only. Never reference protocol, field, security, or deployment rules from `plans/` or `reviews/`.

## Plans

Historical plans live under `docs/plans/` and are not authoritative. Durable rules from completed plans are reflected only in the root-level documents listed above.
